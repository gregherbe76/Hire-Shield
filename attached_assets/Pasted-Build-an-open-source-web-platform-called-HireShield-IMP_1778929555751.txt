Build an open-source web platform called “HireShield”.

IMPORTANT:
This is NOT a paid SaaS.

There must be:
- NO Stripe
- NO subscriptions
- NO payment logic

The project is:
- fully open-source
- GitHub-first
- community-driven
- recruiter and candidate focused

The goal:
Detect suspicious and fraudulent job descriptions using:
- NLP
- heuristic analysis
- embeddings
- metadata intelligence
- LLM reasoning

==================================================
POSITIONING
==================================================

“Open-source recruitment trust intelligence.”

The platform helps users:
- analyze suspicious job posts
- detect scam patterns
- identify ghost jobs
- detect phishing recruitment
- understand trust signals

The system NEVER directly accuses companies of fraud.

Instead it shows:
- trust indicators
- suspicious signals
- confidence levels
- explainable warnings
