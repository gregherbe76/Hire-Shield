# Getting started

This guide gets you a working HireShield instance in under five minutes.

## Option 1 — Docker (recommended)

The fastest path. You'll need [Docker](https://docs.docker.com/get-docker/) with
Compose v2.

```bash
git clone https://github.com/gh63/hireshield.git
cd hireshield
cp .env.example .env
```

Open `.env` and fill in your OpenAI-compatible endpoint:

```ini
AI_INTEGRATIONS_OPENAI_BASE_URL=https://api.openai.com/v1
AI_INTEGRATIONS_OPENAI_API_KEY=sk-...
```

Any OpenAI-compatible endpoint works — OpenAI proper, Azure OpenAI, OpenRouter,
or a local [Ollama](https://ollama.com/) with the OpenAI shim. See
[Configuration](/reference/configuration) for the full list of variables.

Then:

```bash
docker compose up --build
```

When you see `Server listening port=8080`, open <http://localhost:8080>.

::: tip
The `migrate` service runs once and exits — that's expected. It pushes the
Drizzle schema and gets out of the way.
:::

## Option 2 — Local Node.js

You'll need:

- **Node.js 24** (`nvm use 24`)
- **pnpm 9+** (`corepack enable pnpm`)
- **PostgreSQL 14+** running somewhere

```bash
git clone https://github.com/gh63/hireshield.git
cd hireshield
pnpm install
cp .env.example .env   # fill in DATABASE_URL + AI_INTEGRATIONS_OPENAI_*
pnpm --filter @workspace/db run push
```

Then start the API and frontend in two terminals:

```bash
pnpm --filter @workspace/api-server run dev
pnpm --filter @workspace/hireshield run dev
```

## First analysis

Paste any job posting URL or full description at `/analyze`. You'll get back:

- A **trust score** (0–100)
- A **risk level** (`low` / `medium` / `high` / `critical`)
- A **ghost-job probability**
- A list of **detected signals** with severity + plain-language detail
- A **candidate summary** generated by the LLM
- **Recommended actions** to verify the posting before applying

The report has a permalink (`/analyses/:id`) — share it, link it, or pin it.
